2. Les Composants & Props

Un composant est une fonction qui retourne du JSX. Les props sont les paramètres qu'on lui passe.

function Bouton({ texte, couleur }) {
  return <button style={{ color: couleur }}>{texte}</button>;
}

// Utilisation
<Bouton texte="Cliquez-moi" couleur="blue" />

Le hook useState

Le state (état) est la mémoire du composant. Quand le state change, React met à jour l'interface automatiquement.

import { useState } from 'react';

function Compteur() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Vous avez cliqué {count} fois</p>
      <button onClick={() => setCount(count + 1)}>
        Cliquer
      </button>
    </div>
  );
}
🛠️ Exercice Pratique (1h) Défi : Crée un bouton qui alterne entre un texte "Mode Clair" et "Mode Sombre" à chaque clic, en changeant la couleur de fond de la page.
