1. Les commandes de localisation

  • pwd (Print Working Directory) : Affiche le dossier actuel.
  • ls : Liste le contenu du dossier. ls -l pour les détails, ls -a pour voir les fichiers cachés.
  • cd dossier : Entre dans un dossier. cd .. remonte d'un niveau. cd ~ va à la racine de l'utilisateur.

2. Manipulation basique

mkdir mon_dossier  # Créer un dossier
touch fichier.txt  # Créer un fichier vide
cat fichier.txt    # Lire le contenu d'un fichier
Exercice Pratique

Ouvrez un terminal. Allez dans votre dossier personnel (cd ~). Créez un dossier nommé test_linux, entrez dedans, et créez un fichier hello.txt. Vérifiez avec ls -l.

Les commandes de manipulation

cp fichier.txt copie.txt    # Copier
mv fichier.txt /tmp/       # Déplacer (ou renommer)
rm fichier.txt             # Supprimer un fichier
rm -rf mon_dossier         # Supprimer un dossier et son contenu (ATTENTION)
find . -name "*.txt"       # Chercher un fichier
grep "texte" fichier.txt   # Chercher du texte dans un fichier
Conseil de Senior

La commande rm -rf est l'équivalent de formater un disque. Elle ne demande aucune confirmation et ne met rien à la corbeille. Relisez toujours deux fois avant d'appuyer sur Entrée.

1. Comprendre les permissions

Quand vous tapez ls -l, vous voyez des lettres comme -rwxr-xr-x.

  • r (read) : Lecture
  • w (write) : Écriture
  • x (execute) : Exécution (pour les scripts)

2. Modifier les droits

chmod +x script.sh      # Rendre un script exécutable
chmod 755 dossier       # Donner tous les droits au propriétaire
sudo commande           # Exécuter une commande en tant qu'administrateur (root)
Exercice Pratique

Créez un fichier nommé script.sh. Essayez de l'exécuter avec ./script.sh (vous aurez une erreur de permission). Utilisez chmod +x pour corriger le problème.

Surveiller la machine

top            # Moniteur système en temps réel
htop           # Version plus belle de top (à installer)

kill -9 [PID]  # Tuer un processus (utiliser l'ID retourné par ps)
df -h          # Voir l'espace disque

Commandes réseau

ping google.com       # Tester la connexion
curl ifconfig.me      # Voir son IP publique
wget https://site.com/fichier.zip  # Télécharger un fichier

Conseil de Senior

La commande ssh est la porte d'entrée de tous les serveurs Linux du monde. Apprenez à générer une clé SSH (ssh-keygen) pour vous connecter sans taper de mot de passe.

APT (Debian/Ubuntu)

Chaque distribution a son gestionnaire. Sur Ubuntu/Debian, c'est apt.

sudo apt update           # Met à jour la liste des paquets
sudo apt upgrade          # Met à jour les logiciels installés
sudo apt install htop     # Installe un logiciel
sudo apt remove htop      # Désinstalle un logiciel

1. Redirection (>)

Envoyer la sortie d'une commande dans un fichier.

ls -l > liste.txt    # Écrase le fichier
echo "texte" >> log.txt # Ajoute à la fin du fichier

2. Pipe (|)

Le pipe envoie le résultat d'une commande à une autre commande.

ps aux | grep "nginx"       # Cherche nginx dans la liste des processus
cat fichier.txt | wc -l     # Compte le nombre de lignes du fichier
Conseil de Senior

Le pipe (|) est l'outil le plus puissant de Linux. Il vous permet de créer des scripts complexes en une seule ligne de commande en chaînant des petits outils spécialisés.

Le projet : Script de Backup (Bash)

Vous allez écrire un script Bash qui archive un dossier important dans un fichier compressé, avec la date du jour dans le nom.

Cahier des charges :

  • Créer un dossier mes_donnees avec quelques fichiers dedans.
  • Écrire un script backup.sh.
  • Le script doit utiliser la commande tar -czvf pour compresser le dossier.
  • Le fichier de sortie doit s'appeler backup_2023-10-25.tar.gz (en récupérant la date avec date +%Y-%m-%d).
  • Bonus : Faire en sorte que le script supprime les sauvegardes vieilles de plus de 7 jours.
Méthodologie

Commencez par tester chaque commande manuellement dans le terminal. Une fois que tar et date fonctionnent, mettez-les bout à bout dans le fichier .sh. N'oubliez pas le chmod +x.
