1. Variables : let et const

Oubliez var. Utilisez const par défaut (valeur qui ne change pas) et let uniquement si la valeur doit être modifiée.

const nom = "Kevin"; // Ne change pas
let age = 25;        // Peut changer
age = 26;            // OK

2. Conditions et Boucles

const temp = 25;
if (temp > 30) { console.log("Chaud"); } 
else { console.log("Tempéré"); }

for (let i = 1; i <= 3; i++) {
  console.log("Tour " + i);
}
Exercice Pratique

Créez une variable panier. Si le panier contient plus de 100€, affichez "Livraison gratuite". Entre 50€ et 100€, affichez "Livraison 5€". Sinon, affichez "Livraison 10€".

1. Fonctions Fléchées

La syntaxe standard en React. Plus courte et évite les erreurs de contexte this.

// Ancien
function add(a, b) { return a + b; }
// Moderne
const add = (a, b) => a + b;

2. Destructuration et Spread

const user = { nom: "Alice", age: 25 };
const { nom } = user; // Extrait "Alice"

// Cloner et modifier un objet
const userModifie = { ...user, age: 26 };
Conseil de Senior

Le Spread Operator (...) est la clé pour respecter l'immutabilité en React. On ne modifie jamais un objet directement, on le clone en changeant une propriété.

Exercice Pratique

Créez un objet voiture avec marque et modèle. Utilisez la destructuration pour extraire la marque et affichez : "Ma voiture est une [marque]".

Les 3 méthodes essentielles

Indispensables pour afficher des listes en React.

const nums = [1, 2, 3, 4];

// Map : Transformer
const doubles = nums.map(n => n * 2); // [2,4,6,8]

// Filter : Trier
const pairs = nums.filter(n => n % 2 === 0); // [2,4]

// Reduce : Calculer une somme
const total = nums.reduce((acc, n) => acc + n, 0); // 10
Exercice Pratique

Soit users = [{nom: "A", age: 15}, {nom: "B", age: 25}]. Gardez uniquement les majeurs avec filter, puis récupérez uniquement leurs noms avec map.

Async / Await

JavaScript est mono-thread. L'asynchrone permet de ne pas bloquer la page pendant une requête.

async function charger() {
  try {
    const reponse = await fetch('https://api.com/data');
    const data = await reponse.json();
    console.log(data);
  } catch (err) {
    console.error("Erreur réseau", err);
  }
}
Conseil de Senior

N'oubliez jamais le bloc try/catch quand vous utilisez await. Si le serveur est en panne, votre application plantera silencieusement sinon.

Exercice Pratique

Créez une fonction attendre(ms) qui retourne une Promesse et affiche "Fini !" après 2 secondes.
