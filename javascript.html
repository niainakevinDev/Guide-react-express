1. Variables : let et const

Oublie var. On utilise const par défaut (valeur qui ne change pas) et let pour les variables qui doivent être modifiées.

const nom = "Kevin"; // Ne peut pas changer
let age = 25;        // Peut changer
age = 26;

2. Les Types de Données

  • String (Texte) : "Bonjour"
  • Number (Nombre) : 42, 3.14
  • Boolean (Vrai/Faux) : true, false
  • Null (Vide intentionnel) : null
  • Undefined (Pas encore défini) : undefined

3. Les Conditions (if / else)

const temperature = 25;
if (temperature > 30) {
  console.log("Il fait très chaud !");
} else if (temperature > 20) {
  console.log("Il fait bon.");
} else {
  console.log("Il fait froid.");
}

4. Les Boucles (for)

for (let i = 1; i <= 5; i++) {
  console.log("Numéro : " + i);
}

1. Fonctions Fléchées (Arrow Functions)

C'est la syntaxe standard en React. Plus court et évite les erreurs avec this.

// Avant
function additionner(a, b) { return a + b; }
// Après (Moderne)
const additionner = (a, b) => a + b;

2. Template Literals (Backticks)

Fini les concaténations. Utilise les backticks `.

const nom = "Alice";
const message = `Je m'appelle ${nom}.`;

3. Destructuration

Extraire des données d'un objet. Indispensable pour les props de React.

const utilisateur = { nom: "Bob", age: 30 };
const { nom, age } = utilisateur;
console.log(nom); // "Bob"

4. Spread Operator (...)

Copier ou fusionner des objets/tableaux. Tu l'utiliseras tous les jours avec React.

const arr1 = [1, 2];
const arr2 = [3, 4];
const fusion = [...arr1, ...arr2]; // [1, 2, 3, 4]
🛠️ Exercice Pratique (30 min) Défi : Crée un objet voiture avec marque, modele, annee. Utilise la destructuration pour extraire la marque et le modèle. Affiche : "Ma voiture est une [marque] [modele]."

1. .map() : Transformer une liste

const nombres = [1, 2, 3, 4];
const doubles = nombres.map(n => n * 2);
// Résultat : [2, 4, 6, 8]

2. .filter() : Trier une liste

const nombres = [1, 2, 3, 4, 5, 6];
const pairs = nombres.filter(n => n % 2 === 0);
// Résultat : [2, 4, 6]

3. .reduce() : Calculer une valeur globale

const panier = [{ prix: 10 }, { prix: 20 }];
const total = panier.reduce((acc, item) => acc + item.prix, 0);
// Résultat : 30
