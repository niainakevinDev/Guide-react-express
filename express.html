Le serveur. Ici, tu vas créer la partie invisible de l'application : celle qui stocke les données et sécurise l'accès.

📖 Lire le cours et faire l'exercice

1. Initialiser un projet

mkdir mon-api && cd mon-api
npm init -y
npm install express

2. Le serveur de base

Crée un fichier server.js :

const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hello depuis Express !');
});

app.listen(3000, () => {
  console.log('Serveur sur http://localhost:3000');
});
🛠️ Exercice Pratique (1h) Défi : Lance ce serveur avec node server.js. Ouvre ton navigateur sur http://localhost:3000. Ajoute une nouvelle route /api/status qui renvoie un objet JSON { "status": "ok" }.

Le concept de Middleware

Un middleware est une fonction qui s'exécute entre la requête et la réponse. C'est le cœur d'Express.

// Middleware de log
app.use((req, res, next) => {
  console.log(`[${req.method}] ${req.url}`);
  next(); // Passe à la suite
});
🛠️ Exercice Pratique (1h) Défi : Ajoute un middleware qui vérifie si l'URL contient /admin. Si oui, renvoie une erreur 403 (Accès refusé). Sinon, laisse passer avec next().
