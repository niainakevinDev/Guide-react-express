Bien plus qu'un simple terminal : un langage de script orienté objet pour automatiser Windows.

1. La syntaxe Verbe-Nom

Toutes les commandes PowerShell (appelées Cmdlets) suivent le format Verbe-Nom (ex: Get-Help, Set-Location). C'est très intuitif en anglais.

2. Les commandes d'aide

Get-Help Get-Process    # Affiche l'aide sur une commande
Get-Command *service*   # Cherche toutes les commandes avec "service"
Get-Alias               # Voir les raccourcis (ex: ls, cd, cat)

3. Navigation

Get-Location       # Affiche le dossier actuel (équivalent de pwd)
Set-Location C:\   # Change de dossier (équivalent de cd)
Get-ChildItem      # Liste les fichiers (équivalent de ls ou dir)
Exercice Pratique

Ouvrez PowerShell. Tapez Get-Help Get-ChildItem. Essayez ensuite de lister uniquement les fichiers cachés de votre dossier actuel (indice : regardez les paramètres de la commande dans l'aide).

Les commandes de manipulation

New-Item -ItemType Directory -Name "MonDossier"  # Créer un dossier
New-Item -ItemType File -Name "test.txt"         # Créer un fichier
Copy-Item test.txt -Destination C:\Temp\         # Copier
Move-Item test.txt -Destination C:\Temp\         # Déplacer
Remove-Item test.txt                             # Supprimer
Conseil de Senior

PowerShell possède des alias pour les utilisateurs de vieux Windows (cmd.exe). dir, cd, mkdir, del fonctionnent, mais il est recommandé d'utiliser les vrais noms (Get-ChildItem, Set-Location, etc.) dans les scripts pour plus de clarté.

1. Les processus

Un processus est un programme en cours d'exécution (ex: Chrome, Spotify).

Get-Process                     # Voir tous les processus
Get-Process chrome              # Voir les processus Chrome
Stop-Process -Name "notepad" -Force  # Tuer un processus

2. Les services Windows

Les services tournent en arrière-plan (ex: serveur web, mises à jour).

Get-Service                      # Voir l'état de tous les services
Start-Service -Name "wuauserv"   # Démarrer un service
Stop-Service -Name "wuauserv"    # Arrêter un service

1. Select-Object (Sélectionner)

Get-Process | Select-Object Name, CPU, Memory

2. Where-Object (Filtrer)

# Garder uniquement les processus qui utilisent plus de 100 Mo
Get-Process | Where-Object { $_.WorkingSet -gt 100MB }

3. Sort-Object (Trier)

# Trier les processus par CPU décroissant
Get-Process | Sort-Object CPU -Descending
Conseil de Senior

Le symbole $_ représente l'objet actuel dans le pipeline. C'est l'équivalent du "il" ou "l'élément en cours" dans une phrase.

Le projet : Nettoyage des fichiers temporaires

Vous allez créer un script clean.ps1 qui nettoie les fichiers inutiles de Windows.

Cahier des charges :

  • Le script doit cibler le dossier C:\Windows\Temp.
  • Il doit lister tous les fichiers .tmp.
  • Il doit demander à l'utilisateur : "Voulez-vous supprimer ces fichiers ? (O/N)".
  • Si l'utilisateur tape "O", il supprime les fichiers.
  • Si l'utilisateur tape "N", il annule l'opération.
Méthodologie

Pour exécuter un script PowerShell, vous devrez peut-être modifier la politique d'exécution : Set-ExecutionPolicy RemoteSigned -Scope CurrentUser. Testez d'abord votre script en affichant juste les fichiers avec Write-Host avant de passer à la suppression.
